# Neo Mobile Tag Drawer for Flarum

![Neo Mobile Tag Drawer](https://getneotiler.com/social/assets/logo-zohuavye.png)

Neo Mobile Tag Drawer is a sleek, mobile-first extension for Flarum that injects your forum's tags directly into the mobile navigation drawer (hamburger menu). 

Improve your community's mobile navigation and content discovery by bringing categories front-and-center, without affecting the desktop experience.

---

### [EN] Description
A lightweight extension that moves your forum tags from secondary menus to the mobile navigation drawer. Categorize your mobile experience and make it easier for users to find what they're looking for with a single tap.

### [TR] Açıklama
Flarum forumları için geliştirilmiş, mobil kullanıcı deneyimini önceliğe alan bir eklentidir. Forum etiketlerinizi (tags) karmaşık menülerden kurtarıp doğrudan mobil hamburger menüsünün içine taşır. Masaüstü görünümünü bozmadan, mobil kullanıcıların kategorilere tek dokunuşla ulaşmasını sağlar.

---

## 🚀 Key Features

- 📱 **Mobile Optimized:** Tags injected directly into the native hamburger drawer.
- 🎨 **Seamless UI:** Matches Flarum's native icons, alignment, and typography perfectly.
- 🗂 **Smart Sorting:** Follows the priority/positioning you set in the admin panel.
- ⚡ **Lightweight:** Minimal code for maximum performance.
- 🔗 **Home-Click Logo:** Includes a custom centered mobile logo that redirects back to home.

## 🛠 Installation

Install via Composer:

```bash
composer require neotiler/flarum-drawer-tags
```

## 🔄 Updating

```bash
composer update neotiler/flarum-drawer-tags
php flarum cache:clear
```
